# AtomQuest — Goal Setting & Tracking Portal

Built for AtomQuest Hackathon 1.0.

## Features
- Employee — Create goals, live weightage validation, quarterly check-ins
- Manager — Review, approve/return goals, add check-in comments  
- Admin — Analytics dashboard, escalation monitor, audit trail, CSV export

## Quick Start
```bash
pip install flask
python app.py
```
Open http://localhost:5000
